# Closed PRDs And Cards

Practical takeaway: everything in this directory is historical record, not
active execution guidance.

Closed files can explain why a decision was made, what proof closed a slice, or
where a receipt lives. They must not be used as the starting point for new work
unless a current active card explicitly cites them as background. For current
execution, start from:

- `docs/campaign-workflow-protocol.md`
- live cards in `docs/prds/`
- roadmaps in `docs/roadmaps/` whose top-level `status` is `active`
- `docs/core-product-decision-log.yaml`

If a closed file and a live card disagree, the live card and decision log win.
If no live card exists, draft one instead of reviving a closed agenda card.
